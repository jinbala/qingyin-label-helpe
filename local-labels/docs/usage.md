# 使用与维护

## 安装与升级

首次安装加载 `dist/extension/`，不要重复安装同一份轻印。升级先“备份全部模板”，把新版文件覆盖到原来的同一目录，在 Chrome 扩展管理页的原轻印卡片点击重新加载，再刷新所有已打开的商家页面。源码目录也包含独立清单，可直接加载，但必须沿用同一加载路径。

### 模板备份、迁移与更新后看不到模板

在“标签模板”区域点击“备份全部模板”，将当前已保存的全部模板、嵌入图片和位置下载为一个 JSON 文件。该文件不包含商品订单或店铺登录信息。可从扩展弹窗打开模拟验证页，在无需读取商品的情况下备份本机模板。

在另一份轻印中点击“导入备份”，选择整库 JSON。导入会合并模板库，跳过内容及位置完全相同的模板；同编号内容或位置不同时另存副本，保留已有模板。文件校验失败或本机存储写入失败时，不修改页面模板列表，也不提示成功。旧的单个模板 JSON 仍使用“导入 JSON”。

模板数据在浏览器中，保留旧代码文件夹不等于备份模板。换目录加载时，原卡片若仍在，可先回原扩展导出模板，再向新扩展导入；不要先移除原扩展。如果已经移除了原卡片，Chrome 会清除对应的本地扩展存储，仅重装旧目录不能保证找回。此时只能检查此前导出的 JSON、浏览器或系统备份；卸载前未刷新的页面若仍能显示模板，可尝试立即导出。参见 [Chrome 存储说明](https://developer.chrome.com/docs/extensions/reference/api/storage)。

若此前出现 `Failed to fetch dynamically imported module`，使用 v1.4.1 后，先在扩展管理页重新加载轻印，再刷新已打开的 TEMU 页面。此版本补齐了可视化编辑器间接依赖的资源声明。

本扩展只请求五个 TEMU 商家后台域名的权限。没有模板账户、模板服务器、远程图片读取、本地 WebSocket、调试器或网络替换规则。页面通信和本机设置都使用轻印自己的命名空间。

## 创建自己的标签

1. 打开轻印，选择当前店铺和编号类型，读取商品数据。
2. 点击“新建模板”打开可视化设计器；或选中已有本地模板再点击“编辑模板”。
3. 顶部填写模板名称和纸张宽高。左侧添加文字、线框、圆形、商品条码、CODE128、表格或本机图片。新模板自带一个商品条码区域，可选中后删除。
4. 在画布上拖动元素，右下角方块调整大小，双击文字后在右侧编辑。右侧可精确填写毫米坐标、尺寸、旋转、字体和行距，也可对齐到纸张。
5. 左侧图层支持隐藏、锁定、上下调整顺序。顶部支持撤销、重做、缩放及 0.5 mm 吸附；按 Alt 拖动可暂时取消吸附。
6. 点击“保存模板”返回打印。点击首张预览仍可打开位置微调窗口。生成 PDF 后使用标签纸尺寸、100% 缩放，先打印一张核对。

模板保存到本扩展的本机存储，刷新或切换商家页面后仍可使用。v1.4.3 修复了旧页面保存时覆盖新模板的问题，多页面新建会分别保留。保存需通过写入和读回核对；失败会在设计器顶部显示原因，保留当前内容，可修正后重试。扩展弹窗中的模拟验证页与商家页共用本机模板；直接通过本地网站打开的验证页保存在该网站的本地存储中。

v1.4.4 的大图预览会根据窗口大小及屏幕缩放提高分辨率，保留平滑的灰度文字边缘。拖动时仅显示定位提示，松手后刷新标签。屏幕预览与打印使用相同的毫米位置；打印继续生成所选 300/600 DPI 的黑白 PDF，不受预览窗口尺寸影响。

升级不清空 `qingyin-settings/v2` 本地模板；已经被旧版覆盖且没有导出备份的模板无法保证找回。沿用同一扩展和加载目录，避免新装一份后读取不同的存储。可使用“导出模板”另存 JSON 备份。

### 多个发货批次一起打印

在发货单页勾选多个发货批次并读取后，打印明细上方会出现“不同发货批次之间添加提示页”。勾选后，PDF 会在相邻批次之间插入一张区分页：白底、外边框、上下两条黑色粗条，中间居中显示“前后规格不同，请不要贴错”，纸张尺寸与所选模板一致。同批次内不会重复插入；取消勾选则只打印商品标签。“不同 SKU 之间添加提示页”可同时勾选，同一处边界只插入一张。

区分页用于人工分拣时提示前后批次规格不同；它不包含任何商品编号，不能代替商品标签。

### 边框贴边或打印后被裁掉

点击首张预览打开大图，选择“条码框内缩 · 留白 3 mm”，再点“保存位置”，重新生成 PDF。该操作会缩小并居中条码、编号、规格、产地和边框，不移动上方文字；已有模板不会被静默覆盖。若商品条码过大，超出位置微调可处理的范围，需先在设计器缩小元素。

默认 70 × 40 mm 模板的条码区域宽 64 mm，左右及底部至少留白 3 mm，边框为 0.2 mm。纸张尺寸保持不变。此留白是软件默认值，实际可打印范围取决于打印机；仍应使用 70 × 40 mm 纸张和实际大小 / 100% 先试打一张。

文字支持 `{{sku}}`、`{{skc}}`、`{{skuSpec}}`、`{{skcSpec}}`、`{{sourceId}}`、`{{labelCode}}`、`{{origin}}`。右侧“插入商品变量”可插入；打印时替换成当前商品信息。未读取商品时显示虚构示例。请自行填写制造商、地址及责任人等真实标签内容。

快捷键：Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，Ctrl+D 复制元素，Delete 删除，方向键移动 0.1 mm，Shift+方向键移动 1 mm，Ctrl+S 保存，Esc 返回打印。文本框内保留常规文字编辑快捷键。

只接受本机 PNG/JPEG/WebP，单张不超过 2 MB、4096 像素，图片嵌入 JSON。每个模板最多 120 个元素；最终 PDF 为黑白。移出纸张或文字框的内容会被裁切，设计时请检查完整性。“返回打印”不保存本次编辑。

## 模板格式与旧设置

支持轻印 `qingyin-design/v1` 可视化模板和 `qingyin-template/v1` 本地文字模板。导出一份模板即可查看字段。外部对象画布格式、外链图片及服务器模板不支持。v1.3.0 的本地模板与设置可继续使用，点击编辑时自动转换为可视化元素。

首次从旧版升级时，旧设置只备份一次到本扩展存储 `qingyinArchivedSettingsV1`，不加载其中模板；当前设置使用 `qingyinLabelSettings`、格式 `qingyin-settings/v2`。备份不会自动导入或发送到任何服务。

## 验证

`npm.cmd --prefix tests test` 覆盖平台取数、模板边界、设置迁移、位置编辑、拖动频率、预览缓存、PDF 页数与物理尺寸、域名审计，以及复制到无父项目的临时目录后独立构建。

`node tests/render-design-sample.mjs` 生成可视化模板、PNG 与 PDF；`node tests/render-sample.mjs` 生成旧本地文字模板的验证产物。`node tests/benchmark-preview.mjs` 测量 Node + jsdom + native canvas 的模拟交互时间。它不是实际 Chrome 性能数据。

`node tests/render-preview-sample.mjs` 生成预览清晰度对比图和模拟高清位置调整的计时记录，均使用虚构示例内容。

未连接真实账户或打印机时，自动化结果不能替代现场验证。可以从扩展弹窗打开模拟验证页面，测试大图调整和 PDF。
