# Chrome 应用商店资料草稿

名称：轻印标签助手

语言：简体中文

建议分类：工作效率（以当前开发者后台可选分类为准）

简短描述：用于 TEMU 商品标签批量生成、模板管理和 PDF 打印预览的本地扩展。

## 详细介绍

轻印标签助手帮助 TEMU 商家整理商品标签、编辑自己的标签模板，并批量生成适合标签纸尺寸的 PDF。

主要功能：

- 在支持的商家后台页面中读取用户勾选的备货单、发货单或商品 SKU，也支持手动输入编号。
- 核对规格、条码和打印数量，调整打印顺序，按需插入不同 SKU 的提示页。
- 使用可视化设计器添加文字、商品变量、条码、线框、图片或表格，调整图层、位置和尺寸。
- 打开高清大图，按毫米微调位置与缩放，并保存每个模板的位置。
- 在本机生成 300/600 DPI 黑白 PDF，预览后打印或下载。
- 导入、导出轻印模板，备份全部模板及已保存的位置。

使用真实商品数据需要用户在受支持的 TEMU 商家后台登录，并主动点击读取。扩展弹窗也提供模拟数据验证入口，便于在不登录商家账号时检查模板和 PDF 功能。

模板、嵌入图片和 PDF 在本机处理。当前版本没有开发者账号登录、付费订阅、广告或分析统计服务。商品标签请求通过用户已经登录的商家页面发往对应的 TEMU 商家服务。

请使用与标签纸一致的纸张尺寸，并先打印一张核对位置。模板内容和标签要求需要商家自行核对；本工具提供排版和打印功能。轻印为独立工具，与 TEMU 无隶属或官方合作关系。

从开发者模式安装版迁移到商店版前，请先备份全部模板；安装商店版后使用“导入备份”恢复。后续更新沿用同一商店条目。

## 单一用途声明

帮助 TEMU 商家把主动选择的商品标签数据按自定义模板排版并生成本地打印 PDF。

## 权限说明

- storage：在本机保存标签模板、嵌入图片、模板选择及位置设置，支持刷新后继续使用。
- activeTab：用户点击扩展图标时识别当前标签页是否为受支持的 TEMU 商家页面，并向该页面发送打开打印面板的消息。
- 五个商家站点权限：在受支持的 TEMU 商家页面显示工具入口，读取用户主动勾选的编号，利用页面现有登录态请求允许的标签读取接口。权限不覆盖其他网站。

支持站点：seller.kuajingmaihuo.com、agentseller.temu.com、seller.temu.com、agentseller-us.temu.com、agentseller-eu.temu.com。

## 隐私表单填写依据

按当前实现，需要披露本机处理的商品/订单编号、SKU/SKC、条码、商品规格、店铺标识，以及用户填写的模板内容和嵌入图片。模板中可能由用户自行填入名称、地址、联系方式等信息。不要因为数据只在本机处理就声明“不处理任何用户数据”。

当前没有广告追踪、开发者分析统计或开发者服务器上传。扩展不直接读取、保存密码或 Cookie；商品请求利用页面已经建立的登录态。发布者须按提交时后台的实际分类核对并填写数据处理声明。
