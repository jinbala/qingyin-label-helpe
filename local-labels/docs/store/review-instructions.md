# 审核测试说明

## 不需要商家账号的模拟流程

1. 安装扩展，点击工具栏中的“轻印标签助手”图标。
2. 点击“使用模拟数据验证”，打开扩展自带验证页。该页不连接真实商家账号。
3. 点击右下角“轻印标签助手”，再点击“载入示例数据”。
4. 检查两项虚构 SKU、规格和数量。默认数量分别为 2 和 3，未勾选提示页时合计 5 张。
5. 点击“新建模板”，编辑文字、添加线框或条码；填写名称并保存。
6. 点击首张标签预览打开大图，调整位置并保存，关闭后再次打开核对。
7. 点击“生成 PDF 并预览”，验证页显示页数、物理尺寸、下载链接及 PDF 预览。
8. 点击“备份全部模板”下载 JSON，刷新页面确认模板仍在；可使用“导入备份”检查迁移流程。

如果需要验证模拟取数：将编号类型改为“商品 SKU”，勾选验证页中的两条样例记录，再点击“读取页面勾选”。验证页支持正常、空数据、错误、慢请求和缺少编号等模式。

## 真实商品流程

真实功能需要经授权的 TEMU 商家账号、受支持的备货/发货/商品标签页面及可读取的商品数据。用户在商家页面中主动勾选数据后，工具才发起标签读取；默认不会自动登录、提交订单或修改商品。

模拟模式可以检查模板、导入导出及 PDF，但不能替代真实接口验证。如果审核方要求真实流程测试凭据，应由发布者提供专用且获得授权的测试方式；不要把真实店铺密码写入公开商店介绍或源码。

## 资料与验证边界

截至当前准备版本，本地 51 项自动化测试通过。打包内容通过依赖、资源声明和域名审计。真实账号、真实 Chrome、实物打印和双扩展同时启用的系统验收仍未完成，不能将自动化结果描述为已通过现场测试。
