# v1.4.5 验证

- `own-template.json`：轻印原生模板，文字使用虚构公司和样例地址，无图片资源。
- `own-label.png`：300 DPI、70 × 40 mm、827 × 472 像素的渲染样例。
- `own-labels.pdf`：两项虚构 SKU 各三张，加一张规格提示页，共七页。
- `preview-performance.json`：Node + jsdom + native canvas 模拟的 20 次整体位置调整，不代表真实 Chrome 的帧率或延迟。
- `designer-template.json`、`designer-label.png`、`designer-labels.pdf`：使用轻印可视化元素生成的模板、300 DPI 图像和两页 PDF。

51 项自动化测试覆盖模板格式隔离、旧数据备份停用、DOM 操作、设计器新增/对齐/复制/图层/锁定/撤销/保存、100 次拖动不重建条码、本机图片嵌入与打印、保存失败后重试、底图缓存、300/600 DPI 渲染、相同 DPI 下标签渲染与 PDF 图像逐位一致、PDF 页数和尺寸，以及复制项目到无原扩展的临时目录后构建并解包。

本次新增整库备份回归：两份相互独立的存储通过 JSON 迁移完整模板、嵌入图片及毫米位置；导出读取其他页面刚保存的数据，且不会改变当前页面保存差异的基线；相同模板跳过、冲突编号另存；混入外部对象模板、重复编号或无效位置时整份拒绝且保持当前库；模拟配额不足时界面和已有数据不变，重试成功并重新挂载后仍可恢复所有模板和位置。测试使用内存存储和 jsdom，不证明已恢复用户在 Chrome 卸载时删除的数据。

本次新增高清预览回归：70 × 40 mm 大图按实际显示区域及 1×/2× 像素密度选择分辨率；小字保留中间灰阶；100 次连续拖动不重绘条码，整体移动松手后复用底图；30 次窗口/像素密度变化合并为一次更新，画布自身大小变化不产生重绘循环；页面关闭断开尺寸观察。最长边限制为 3200 像素，总像素预算约 400 万，PDF 继续采用所选 300/600 DPI，预览和打印的毫米位置一致。

`preview-quality-comparison.png`、`preview-quality.json` 由 `render-preview-sample.mjs` 生成，内容为虚构示例。816 px 显示区域的 1× 屏幕示例中，旧 180 DPI 预览仅 496 px 宽，新预览 456 DPI、1257 px 宽；2× 屏幕使用 912 DPI。本地 Node + jsdom + native canvas 的 20 次高清整体位置调整约 683 ms，此值不是 Chrome 性能数据，也不能证明真实页面帧率。本次未发现可连接浏览器，实际 Chrome 显示仍需现场验证。

本次模板持久化回归覆盖：两个旧页面同时新建，后续切换模板、保存位置、删除其中一个模板后，另一页的模板及位置仍保留；模拟配额错误和静默丢写，不得返回保存成功，失败后可重试；经扩展消息桥接保存真实设计器输出，旧页面再保存后重新挂载界面，新模板仍可打开编辑；后台拒绝非本扩展或非商家/验证页的模板读写。上述 Chrome 存储和消息接口使用测试替身，并非真实浏览器验证。

新增条码留白检查：新建 70 × 40 mm 标签的条码框宽 64 mm、左右及底部留白至少 3 mm；已有贴边、旋转、放大边框、父级缩放布局可通过按钮内缩，保留上方文字的布局参数。203/300/600 DPI 的软件渲染经模拟 2 mm 纸边裁切后仍保留四条完整边框，PDF 页面继续保持 70 × 40 mm。该模拟不代表实际打印机测试。

本次新增页面资源声明检查，递归覆盖 `app.mjs` 的间接模块、运行服务入口和模块样式，核对五个站点的资源访问声明。测试在移除 `design-svg.mjs` 的声明时能复现失败，并验证单个站点漏配也会报错。此项为清单和依赖图检查，不等同于真实 Chrome 扩展加载测试。

运行时不含服务器模板、外链图片、旧画布模板库、原插件协议或本地 WebSocket。依赖校验及独立性审计在构建时执行；审计范围与规则见 `scripts/independence-audit.mjs`。

未验证真实账号取数、双扩展同时启用或实物打印机。自动化页面环境使用 jsdom，不能替代 Chrome 现场验证。
