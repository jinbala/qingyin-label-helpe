# 轻印标签助手

轻印标签助手是一个运行在 **TEMU 商家后台**里的 Chrome 扩展，用于把勾选的备货单、发货单或商品 SKU 批量排成 **70 × 40 mm 等标签纸**，在本机生成黑白 PDF，预览后直接打印。它同时提供一个可视化标签模板设计器，模板、嵌入图片和排版位置都保存在浏览器本地。

- **面向谁**：需要按 SKU 批量打印合规标签 / 商品标签的 TEMU 商家。
- **在哪里运行**：`seller.kuajingmaihuo.com`、`agentseller.temu.com`、`seller.temu.com`、`agentseller-us.temu.com`、`agentseller-eu.temu.com` 五个商家后台。
- **数据去哪**：商品数据由当前商家页面使用已有登录态请求；模板、图片和 PDF 只在浏览器本机处理。没有开发者服务器、账号、广告、统计或远程模板。
- **不做什么**：不保存或读取账号密码、Cookie；不替换页面网络请求；不读取浏览历史；不兼容外部对象画布模板或外链图片。

版本 **1.4.9**。完整变更见 [CHANGELOG.md](CHANGELOG.md)，操作细节见 [docs/usage.md](docs/usage.md)。

## 主要能力

### 从商家后台取数并打印

- 在备货单、发货单、商品标签页读取当前勾选，或手动输入编号。
- 发货单页按“发货批次”读取整批发货单，不会只取批次行里的第一条。
- 可调整每项打印数量、打印顺序（页面顺序 / 勾选顺序 / SKC / 时间），在 SKU 或发货批次之间插入提示页。
- 生成 300 / 600 DPI 黑白 PDF，按标签纸实际毫米尺寸输出；打印页提供预览、打印和下载。
- 大批量或含大图的模板会在生成前按唯一标签数量做体积预检，生成过程中也会累计压缩体积；超过 12 MB 前就会提示减少 SKU、改用 300 DPI 或分批打印。

### 本地模板与设计器

- 可视化设计器支持文字、线段、矩形、圆形、商品条码、CODE128、本机图片和表格；可调毫米坐标、尺寸、旋转、字体、对齐、图层顺序、锁定、撤销重做和网格吸附。
- 点击首张预览可打开大图，按“整张标签 / 上方文字 / 条码区域 / 各文字块”拖动或输入毫米偏移与缩放，位置按模板保存。
- 支持 `{{sku}}`、`{{skc}}`、`{{skuSpec}}`、`{{skcSpec}}`、`{{sourceId}}`、`{{labelCode}}`、`{{origin}}` 变量。
- 模板格式为轻印自己的 `qingyin-design/v1`（可视化）和 `qingyin-template/v1`（本地文字），可导出 / 导入 JSON。

### 模板备份与多页面协作

- “备份全部模板”把模板、嵌入图片和位置导出为一个 JSON；“导入备份”合并到另一份轻印，冲突时另存副本，不覆盖已有模板。
- 多标签页同时编辑时，只提交本页实际改动的模板和位置，旧页面不会覆盖其他页面新建的模板。
- 模板总量接近浏览器为本扩展保留的 10 MB 时，保存前会提示并拒绝；损坏的单条模板或位置只会被跳过并保留，不会触发其他模板的删除。

## 隐私与权限

| 权限 / 域名 | 用途 |
| --- | --- |
| `storage` | 保存本机模板、嵌入图片和位置设置 |
| `activeTab` | 从扩展弹窗识别当前商家标签页并打开面板 |
| 五个 TEMU 商家域名 | 在对应页面显示入口、读取用户勾选的编号、使用页面登录态请求标签数据 |

- 没有 `unlimitedStorage`、`debugger`、`declarative_net_request`、`<all_urls>`，也不加载远程代码。
- 商品与翻译请求只发往 TEMU 商家服务；模板、图片和 PDF 不上传。
- 生成的 PDF 暂存在扩展本机 IndexedDB，24 小时后过期，并在后续生成时清理。
- 换目录或移除扩展可能改变扩展身份并清空本地存储，操作前请先“备份全部模板”。

## 安装与升级

1. 获取或构建 `dist/extension/`（见下方“开发与验证”）。
2. 打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，加载 `dist/extension/`。
3. 打开 TEMU 商家后台，右下角出现“轻印标签助手”入口；也可点击扩展图标从弹窗打开。

升级时：

1. 先在旧版本中“备份全部模板”。
2. 把新版文件覆盖到**原来的同一目录**。
3. 在扩展管理页的原轻印卡片点击“重新加载”。
4. **刷新所有已打开的商家页面**。

不要通过“移除扩展再重装”来升级；不要同时加载两份轻印。源码目录也包含独立清单，可直接加载，但必须沿用同一加载路径。

## 快速使用

1. 在 TEMU 的备货单 / 发货单 / 商品标签页勾选记录。
2. 打开轻印，选择“当前店铺”、编号类型，点击“读取页面勾选”或输入编号。
3. 核对规格与数量，选择模板；点击首张预览可打开大图调整位置。
4. 选择 300 / 600 DPI，点击“生成 PDF 并预览”。
5. 在打印页使用标签纸尺寸、**实际大小 / 100%** 缩放，先打印一张核对条码与内容。

首次使用建议先用扩展弹窗里的“使用模拟数据验证”页面走一遍流程，不需要真实店铺或打印机。

## 技术结构

```text
src/core/          平台取数、模板格式、位置与存储占用计算
src/integration/   页面读取、页面请求桥接、扩展入口与域名判定
src/ui/            操作面板、模板设计器、大图位置调整
src/printing/      标签排版、CODE128、1-bit PDF 与打印预览
assets/icons/      图标原稿与多尺寸 PNG
vendor/            JsBarcode、pdf-lib 及校验值
preview/           模拟数据验证页面
tests/             自动化测试与示例产物
scripts/           资源/独立性审计、构建与商店材料
docs/              使用说明、评审与需求文档
dist/extension/    可加载的独立扩展（构建产物，不入库）
```

扩展为 **零构建 MV3 扩展**：源码可直接加载，运行时只依赖 `vendor/` 中两个 MIT 库。构建脚本用纯 Node 写入 ZIP，并回读校验每个条目的长度与 CRC；打包采用文件白名单。

## 开发与验证

需要 Node.js 22。不需要 Python，也不需要打包器。

```bash
npm install              # 根目录开发依赖（c8、prettier）
npm --prefix tests ci    # 测试依赖（jsdom、@napi-rs/canvas）
npm test                 # 自动化测试
npm run check            # 清单资源、语法、依赖与独立性审计
npm run build            # 打包 dist/extension 与 zip，并回读校验
npm run coverage         # 覆盖率报告
npm run format           # Prettier 格式化 CSS / JS
```

Windows PowerShell 中把 `npm` 写成 `npm.cmd` 即可。CI（GitHub Actions）会安装测试依赖、运行测试、连续构建两次并比较安装包 sha256。

测试覆盖取数、模板校验、设置迁移、位置编辑、预览缓存、PDF 尺寸与像素、存储配额、损坏数据加载、CODE128 错误、内容缩放、备份合并、域名审计，以及复制到空目录后的独立构建。真实账号、真实打印机和商家页面改版仍需现场验证。

## 兼容性与已知限制

- Chrome 111+（依赖 `world: "MAIN"` 内容脚本）。
- 只支持上方五个商家域名和轻印自己的模板格式。
- 单个 PDF 上限 12 MB；模板与图片合计约 10 MB。大批量请减少 SKU、使用 300 DPI 或分批打印。
- 页面结构或 TEMU 接口变化可能导致读取失败；出错时会给出可读提示，必要时使用手动编号。
- 软件中的居留与留白是默认值，实际可打印范围取决于打印机，请先试打一张。
