# 轻印标签助手

独立的 TEMU 标签打印扩展，版本 **1.4.6**。使用自己的名称、图标、页面入口、通信协议和存储；模板与 PDF 在本机生成。

首次安装时，Chrome 打开 `chrome://extensions`，选择“加载已解压的扩展程序”，加载 **`dist/extension/`**。升级现有安装时，先备份全部模板，将新版文件覆盖到原来的同一目录，在原轻印卡片点击重新加载，再刷新 TEMU 页面。不要通过移除扩展再重装来更新。

v1.4.6 修复发货单页（`/main/order-manager/shipping-list`）只打印一个发货单的问题：勾选“发货批次”时会读取该批次下全部发货单号，不再只取行内第一条。发货批次与物流信息单元格使用跨行合并，其余发货单行没有自己的勾选框；旧版本只按勾选行取一个编号，因此整批只生成一张标签。

v1.4.5 增加“备份全部模板”和“导入备份”，将本机模板、嵌入图片及已保存的位置导出为单个 JSON，支持迁移到另一份轻印。导入会保留已有模板，同编号冲突另存副本；校验或保存失败时不报告成功。模板保存于浏览器的扩展存储，插件代码文件夹不是数据备份。换目录可能换扩展身份，移除扩展会清除它的本地存储；已经移除且没有导出或其他备份的模板无法保证找回。

v1.4.4 修复大图预览放大后小字模糊、断笔：按显示区域与屏幕像素密度生成高清图像，保留文字边缘的灰度抗锯齿，窗口大小或缩放变化后自动更新。保留底图缓存和拖动松手后更新，限制预览图像尺寸，避免逐帧重新生成条码。打印继续按用户选择的 300/600 DPI 生成黑白 PDF。

v1.4.3 修复“保存成功后刷新丢失”：后台串行合并各页面实际修改的模板和位置，旧页面切换模板或保存位置不会再覆盖其他页面新建的模板。写入后读回核对，成功才关闭设计器；失败在顶部显示原因并保留编辑内容。模拟验证页也改用持久存储，从扩展打开时与商家页共用模板。升级后请刷新所有已打开的 TEMU 页面。

v1.4.2 将默认条码框纸边留白增加至 3 mm，边框线宽改为 0.2 mm。大图调整窗口新增“条码框内缩 · 留白 3 mm”，可对已有模板的条码区域缩小、居中，保留上方文字和 70 × 40 mm 纸张尺寸。设置后需保存位置并重新生成 PDF。实际打印仍需核对驱动缩放与纸张设置。

v1.4.1 修复了 `design-svg.mjs` 缺少网页资源声明导致的初始化失败。构建现在递归检查页面模块的所有间接导入与样式文件，并逐一核对五个商家站点的访问声明。

## 功能

- 读取当前店铺勾选的商品，或手动输入备货单、发货单、SKU 编号。
- 可视化模板设计器：文字、线段、矩形、圆形、商品条码、CODE128、本机图片和表格；支持图层、毫米标尺、网格吸附、对齐、旋转、复制、锁定和撤销重做。
- 新建或编辑模板会打开三栏设计窗口；旧本地文字模板可以直接转换为可视化模板，已有信息与位置会保留。
- 点击首张预览打开大图；拖动或输入毫米偏移、缩放，按模板保存位置。
- 批量生成黑白 PDF，支持数量、顺序、规格提示页及 300/600 DPI。
- 导入、导出轻印自己的 `qingyin-design/v1` 可视化模板 JSON，也兼容 `qingyin-template/v1` 本地文字模板。

v1.3.0 移除了第三方模板服务、远程图片和旧画布对象模板兼容层。旧版设置保存在本扩展的 `qingyinArchivedSettingsV1`，升级后停用旧模板并使用新的本地模板。参考资料不在本项目或安装包内。标签内容需自行填写，不提供导入商信息。

## 目录

```text
src/core/          平台数据、模板格式与位置设置
src/integration/   页面读取、通信与扩展入口
src/ui/            操作面板、模板编辑与大图位置调整
src/printing/      标签排版、PDF 与打印预览
assets/icons/      轻印图标原稿与 PNG
vendor/            开源依赖、许可证、校验值
preview/           模拟数据验证页面
tests/             自动化测试与示例生成
scripts/           独立性审计、校验和构建
docs/              使用说明与验证产物
dist/extension/    可加载的独立扩展
```

## 开发与验证

在本目录执行：

```powershell
npm.cmd --prefix tests ci
npm.cmd --prefix tests test
node scripts/build.mjs
```

整个目录可复制到任意位置；构建无需读取父目录文件。打包采用白名单，独立性审计会检查运行时域名、权限、依赖和旧协议残留。测试包含单独复制项目后的真实构建。

运行时仅保留直接取自 npm 的 JsBarcode 和 pdf-lib，均为 MIT 许可，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。此前对参考软件的分析历史不等于从未接触过其实现；本版本的可验证边界是移除其服务、文件、图片和模板依赖，并重写标签分区排版。

更多操作见 [docs/usage.md](docs/usage.md)。
